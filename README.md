# StreamWave для телефона и телевизора

Текущая версия: **1.2.5**, Android 8.0+.

- [Скачать APK для телефона](https://github.com/maxwell2010/StreamWave-Releases/releases/download/last_relise/StreamWave.apk)
- [Скачать APK для Android TV / Google TV](https://github.com/maxwell2010/StreamWave-Releases/releases/download/last_relise_tv/StreamWave-TV.apk)

Для каждой платформы сохранен постоянный адрес загрузки. Прежние версии остаются архивными черновиками. TV имеет отдельный пакет, плитку в главном меню, горизонтальный интерфейс и управление пультом. Проверено на эмуляторе Google TV Android 16; физический телевизор еще не проверен.

В 1.2.3 добавлены анимированная заставка загрузки, настоящий полный экран и режимы масштаба, остановка потока при блокировке телефона и прокрутка длинного описания обновления с видимыми кнопками. Исправлены переход из браузера в плеер и ложная ошибка очистки Success.

Magnet/.torrent, ограниченный буфер с автоматической очисткой, плейлист, сортировка, перемотка, темы, настраиваемые зеркала и проверка обновлений.

**Известная проблема:** Google Play Protect классифицировал телефонную 1.2.2 как generic_malware. Обращение отправлено, отмена классификации не подтверждена. Результат VirusTotal 0/66 относится только к 1.2.2 и не отменяет отдельную классификацию Play Protect. Для 1.2.3 и TV подтверждения одобрения Play Protect нет.

Release-сборки без возможности отладки, прежний сертификат сохранен. Пакеты: `ru.streamwave.player` и `ru.streamwave.player.tv`; versionCode 11. Проверяются размер, SHA-256, пакет, версия и подпись перед установкой обновления. Контрольные суммы включены в каждый релиз. Данные и плейлисты телефона и TV независимы.

Публичный репозиторий содержит APK, метаданные обновлений и пользовательскую документацию. Исходники и ключи хранятся отдельно.

В 1.2.4 добавлен наш канал [@MintStreamWave](https://t.me/MintStreamWave) и поиск по его публичным публикациям. Канал добавляется в существующую библиотеку с сохранением пользовательских источников; его можно удалить.

В 1.2.5 добавлены настраиваемые уведомления о кино. Включите их в настройках «Новинки кино и уведомления», выберите частоту 1/6/24 часа, постеры и использование сети без лимита. По нажатию открывается карточка фильма. По умолчанию выключены; старые посты при включении не рассылаются. Приложение получает только подтвержденные публикации канала. Android может отложить проверку; на физическом TV показ зависит от прошивки.
