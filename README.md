# StreamWave для Android

Публичные APK приложения StreamWave. Исходники разрабатываются в отдельном приватном репозитории.

**[Скачать последнюю версию APK](https://github.com/maxwell2010/StreamWave-Releases/releases/latest/download/StreamWave.apk)**

[Все выпуски и изменения](https://github.com/maxwell2010/StreamWave-Releases/releases)

## Установка и обновление

Android 8.0 и новее. Скачайте APK и откройте его на устройстве. Android может попросить разрешить установку из этого источника. Устанавливайте новую версию поверх старой, чтобы сохранить плейлист и настройки.

Начиная с 1.2 приложение проверяет наличие новых версий при запуске. Проверка доступна и в настройках. При наличии обновления можно скачать APK, проверить его и открыть системную установку Android. Контрольная сумма, пакет, номер версии и сертификат подписи проверяются до установки.

Пользователям 1.0 и 1.1 нужно один раз скачать и установить 1.2 по ссылке выше. В ранних версиях онлайн-проверки ещё нет.

## Возможности

Просмотр magnet и .torrent до полной загрузки, дисковый буфер 8-256 МБ с удалением старых окон, плейлист, перемотка и полный экран, светлая и тёмная темы. Поиск по источникам с русскоязычным видео и автоматический выбор доступного адреса из настроенного списка зеркал.

Это тестовая сборка. Для потока нужны доступные пиры и скорость; кодеки и доступность сайтов зависят от устройства и сети. Ограничение буфера относится к видеоданным на диске, служебные данные и RAM учитываются отдельно. Если все адреса источника недоступны, приложение покажет ошибку.

## Публичный канал обновлений

[update.json](https://github.com/maxwell2010/StreamWave-Releases/releases/latest/download/update.json) всегда относится к последнему опубликованному выпуску и содержит номер версии, адрес конкретного APK, размер и SHA-256. Для скачивания и проверки не нужен аккаунт GitHub.

Каждый выпуск содержит APK, update.json и SHA256SUMS.txt. В репозиторий не загружаются исходники приложения, ключи подписи и данные пользователей.
