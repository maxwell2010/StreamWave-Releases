# StreamWave для Android

StreamWave 1.2.1 - плеер для magnet и .torrent. Android 8.0+.

**Известная проблема:** при проверке Google Play Protect заблокировал установку APK 1.2.1 с предупреждением «This app may be harmful» и классификацией POTENTIALLY_UNWANTED / generic_malware. Причина пока не установлена, разбор продолжается. Публикация не означает, что проверка Play Protect пройдена.

Сертификат приложения сохранён для совместимости обновлений. Пакет: `ru.streamwave.player`, версия: `1.2.1`, versionCode: `4`. Контрольная сумма APK опубликована в файле SHA256SUMS.txt релиза. Канал обновлений: [update.json](https://github.com/maxwell2010/StreamWave-Releases/releases/latest/download/update.json).
